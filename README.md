# WePlay

A browser game (Snake) written in plain HTML/CSS/JavaScript — no build step.

Play locally: open `index.html`, or run `python3 -m http.server` and visit http://localhost:8000.

## Hosting on GitHub Pages
1. Merge to `main`.
2. In the repo go to **Settings → Pages → Source: GitHub Actions**.
3. The included workflow deploys the site to `https://<user>.github.io/WePlay/`.
